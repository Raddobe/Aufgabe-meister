# AufgabenMeister 📚

**Dein smarter Lern- und Prüfungsplaner** — یک برنامه‌ریز هوشمند مطالعه و آزمون

یک اپلیکیشن وب برای مدیریت وظایف، برنامه‌ریزی مطالعه و پیگیری پیشرفت در آمادگی برای آزمون زبان آلمانی B2.

![Next.js](https://img.shields.io/badge/Next.js-16-black)
![TypeScript](https://img.shields.io/badge/TypeScript-5-blue)
![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-4-38bdf8)

## ✨ ویژگی‌ها

- 📋 **مدیریت وظایف** — ایجاد، ویرایش و ردیابی وظایف مطالعه
- 📅 **تقویم تعاملی** — مشاهده رویدادها و مهلت‌های ماهانه
- 📊 **آمار و نمودار** — ردیابی فعالیت‌های هفتگی و پیشرفت
- 🌙 **حالت تاریک** — رابط کاربری تطبیقی
- 📱 **ریسپانسیو** — بهینه برای موبایل و دسکتاپ
- 🎯 **اولویت‌بندی** — وظایف با درجه Hoch/Mittel/Niedrig
- 🔄 **فیلترها** — Alle/Heute/Wichtig/Erledigt

## 🚀 راه‌اندازی

```bash
# کلون ریپو
git clone https://github.com/YOUR_USERNAME/AufgabenMeister.git
cd AufgabenMeister

# نصب وابستگی‌ها
npm install
# یا
bun install

# اجرا
npm run dev
# یا
bun run dev
```

بعد بروید به [http://localhost:3000](http://localhost:3000)
